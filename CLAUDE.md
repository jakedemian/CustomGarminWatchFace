A Connect IQ watch face for Jake's Forerunner 970. It's a personal sideload; there are no Store plans yet. Jake drives the design. Claude does the Monkey C, builds, and simulator runs.

## Current design (approved)
Black background, 454×454 round AMOLED. Everything is drawn directly with `Dc` in `source/WatchFaceView.mc`; there are no layout XML files. Y positions are offsets from the screen center `cy`:

| Element | Position | Font | Color |
|---|---|---|---|
| Battery icon + `%` | `cy - 175`, icon and text centered as a group | Vector RobotoRegular, `BATTERY_FONT_PX = 27` | light gray |
| Date `SAT   OCT 10` | `cy - 132`, weekday, 22px gap, then month+day | Vector RobotoRegular, `DATE_FONT_PX = 41` | gray, month red |
| Time `1054` | centered at `cy` | Custom bitmap fonts (below) | white |
| HR row | `cy + 115`, row centered on its own | `FONT_SMALL` | white text, red heart |
| Steps row | `cy + 157` (`rowGap = 42`), row centered on its own | `FONT_SMALL` | white text, teal icon `0x00C8A0` |

Time details:
- 12-hour, no AM/PM, **no colon**. Hours are heavier, minutes thinner.
- Centered by **ink width**, not advance width, so it's truly equidistant from both edges. `TIME_GAP = 12` sits between the hours and minutes.
- Hours: Roboto weight 400. Minutes: weight 100 + thinning 3 ("thin B"). Size 175px ("size B"; "size A" = 165px). Digit height is about 128px.
- HR and steps rows are each centered independently, so their icons are deliberately not aligned. Jake chose this.

Data sources:
- **Battery**: `System.getSystemStats().battery`.
- **Date**: `Gregorian.info(now, FORMAT_MEDIUM)`, uppercased.
- **HR**: `Activity.getActivityInfo().currentHeartRate`, falling back to the latest `ActivityMonitor.getHeartRateHistory` sample. Shows `--` when there's no value.
- **Steps**: `ActivityMonitor.getInfo().steps`, comma-formatted.

Always-on (low-power) mode:
- Active only when sleeping **and** `requiresBurnInProtection` is set.
- Same layout, with a dim palette: `0x666666`, `0x444444`, dim red, dim teal.
- The whole face shifts by up to 3px each minute (`BURN_IN_SHIFTS`).
- Garmin's rule: under 10% of the screen's luminance, avoid white and blue, update once per minute.
- **Not yet verified on the real watch or in the simulator.**

## Build / run
```powershell
.\build.ps1          # builds bin\WatchFace.prg for fr970, signed with ~\.connectiq\developer_key.der
.\build.ps1 -Run     # also starts the simulator if needed and loads the face
```
- From the Bash tool, run `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1`.
- **`monkeydo` never exits.** It stays attached and streams the app's console output. From Bash, run it with `run_in_background`:
  `"$(cat "$APPDATA/Garmin/ConnectIQ/current-sdk.cfg" | tr -d '\r\n')/bin/monkeydo.bat" bin/WatchFace.prg fr970`
  Each new load replaces the previous one, and the old background task then "completes". That's expected; don't report it. Its output file is where runtime errors and crashes would appear, so check it if something looks wrong.
- Claude can't see the simulator. Ask Jake for a screenshot after visual changes.
- The only build warning is that the launcher icon (24×24 template SVG) gets scaled to 65×65. It's a placeholder.

## Fonts
- Custom time fonts are bitmap BMFont files (`.fnt` + `.png`), generated by `tools/gen_font.py` from `fonts-src/Roboto-VF.ttf`. That's a variable Roboto (OFL, license in `fonts-src/OFL.txt`) with Weight 100–900 and Width axes.
  ```
  python -I tools/gen_font.py fonts-src/Roboto-VF.ttf <weight> <px> 0123456789 resources/fonts/<name> <tracking=4> [thin]
  ```
  The exact current arguments are in the comment in `resources/fonts/fonts.xml`. Hours and minutes must use the same px size.
- The generator normalizes metrics: `xoffset=0`, `xadvance = ink width + tracking`, and line height = digit height. That's what makes ink-centering and `TEXT_JUSTIFY_VCENTER` exact. If you change `tracking`, update `TIME_TRACKING` in the view to match.
- `thin` goes below Roboto's lightest weight. It renders at 4×, erodes N supersampled pixels per side, then downsamples. Each step is about 0.5px thinner.
- Pillow 9.4's `getbbox` returns advance width rather than ink for some glyphs (the "1" came out as wide as the "0"). That's why the generator crops from rendered pixels instead.
- `FONT_XTINY` is the smallest built-in font (about 31px). For anything smaller, or for in-between sizes, use `Graphics.getVectorFont({:face => "RobotoRegular", :size => px})` with a built-in fallback. Faces available on fr970: RobotoRegular, RobotoItalic, RobotoCondensedRegular, RobotoCondensedBold, and some non-Latin faces. There's no thin system font.

## Device facts (verified from `%APPDATA%\Garmin\ConnectIQ\Devices\fr970\`)
- Device id `fr970`, family `round-454x454`. AMOLED, 16 bpp, touch, 326 ppi.
- Connect IQ API 6.0.3. SDK 9.2.0 is installed. `minApiLevel` in the manifest is 5.0.0.
- **Watch face memory limit: 128 KB.**
- Complications exist for weekly run distance, training status, recovery time, VO2 max, race predictors, Body Battery, stress, sleep score, calendar, and weather. There is **no** training readiness, HRV, or next-workout complication.
- To check whether an API exists, grep `Devices\fr970\fr970.api.debug.xml`. SDK docs are in `<sdk>\doc\` (for example `doc\docs\Connect_IQ_FAQ\How_Do_I_Make_a_Watch_Face_for_AMOLED_Products.html`). Monkey C training data is thin, so verify there before relying on memory.

## Monkey C gotchas hit so far
- Fonts loaded with `WatchUi.loadResource(Rez.Fonts.X)` are typed **`WatchUi.FontResource`**, not `Graphics.FontResource`. The compiler errors on the latter.
- The compiler type-checks: cast `Gregorian.Info` fields (`day_of_week as String`), and use `has :symbol` checks for optional APIs.

## Deploy to the watch
1. Plug in over USB. It appears in Explorer as "Forerunner 970" (MTP, no drive letter).
2. Copy `bin\WatchFace.prg` into `Internal Storage\GARMIN\APPS`.
3. Eject, then unplug.
4. On the watch, select the face ("Jake Run Face").

WSL can't see the watch over MTP. Scripting the copy would need PowerShell `Shell.Application`; Jake was offered this but it isn't built. A crashed face shows "IQ!". Logs should be in `GARMIN\APPS\LOGS\` (the exact filename is unverified).
